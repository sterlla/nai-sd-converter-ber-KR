# NAI → SD 프롬프트 변환기

NovelAI의 `가중치::…::` 블록 문법을 Stable Diffusion(A1111 / ComfyUI)이 읽는
`(태그:1.4)` 형식으로 변환합니다. 음수 가중치는 네거티브 프롬프트로 자동 분리하고,
문법이 깨진 자리는 원문에서 직접 짚어 그 자리에서 고칠 수 있습니다.

**HTML 파일 하나가 전부입니다.** 설치도, 빌드도, 인터넷 연결도 필요 없습니다.

---

## 쓰는 법

`index.html`을 브라우저로 열면 끝입니다. 더블클릭하거나 브라우저 창에 끌어다 놓으세요.

1. 왼쪽 위 칸에 NAI 프롬프트를 붙여넣습니다
2. 오른쪽에 Positive / Negative가 갈라져서 나옵니다
3. 각 칸의 **복사** 버튼을 눌러 SD의 해당 칸에 붙여넣습니다

평소 쓰는 네거티브가 있으면 왼쪽 아래 칸에 넣으세요. 자동 추출된 것과 합쳐집니다.

---

## 변환 규칙

| NAI | SD | 설명 |
|---|---|---|
| `2::a,b::` | `(a:2.0), (b:2.0)` | 닫는 `::`까지 블록 안 **전부**에 적용 |
| `1.4::a::` | `(a:1.4)` | SD엔 블록 가중치가 없어 태그마다 풀어씀 |
| `1.2::x,1.5::y::,z::` | `(x:1.2), (y:1.5), (z:1.2)` | 중첩 모드가 "곱하기"면 y는 1.8 |
| `-2::a::` | `(a:1.2)` → 네거티브 | SD엔 음수 가중치가 없어 채널을 옮김 |
| `-6::a::` | `(a:1.6)` → 네거티브 | `1 + |w| × 0.1`, 최대 1.8 |
| 가중치 1 | `tag` | 괄호 없이 그대로 |

### 자주 헷갈리는 것

`2::a, b, c::` 에서 가중치 2는 **`a` 하나가 아니라 `a` `b` `c` 전부**에 걸립니다.
닫는 `::`까지가 한 블록입니다. 일부만 올리려면 블록을 쪼개세요.

```
2::a::,b,c              ← a만 2.0
2::a,b,c::              ← a, b, c 전부 2.0
```

## 문법 검사

입력창 안에서 문제 있는 자리가 **빨강(오류) / 노랑(경고)** 으로 표시됩니다.

| 문제 | 심각도 | 자동 수정 |
|---|---|---|
| 안 닫힌 블록 | 오류 | 끝에 `::` 추가 |
| `artiat:` 등 오타 | 오류 | `artist:` 로 교정 |
| `artist:artist:` 중복 | 오류 | 하나로 |
| `rating:explicit` + 가중치 | 오류 | 콜론 → `_` |
| 중복 태그 | 경고 | 뒤쪽 삭제 |
| 가중치 0 | 경고 | 수동 확인 |
| 가중치 2.5 초과 | 경고 | 수동 확인 |
| 아티스트 15개 초과 | 경고 | 수동 확인 |

**보기** 를 누르면 해당 위치가 선택되고, **고칠 수 있는 것 전부** 로 한 번에 처리합니다.
잘못 고쳤으면 **되돌리기**.

콜론이 들어간 태그에 가중치가 붙으면 `(rating:explicit:1.4)` 가 되는데,
SD는 마지막 콜론만 가중치로 읽어 태그가 깨집니다. 그래서 오류로 잡습니다.

## 옵션

| 옵션 | 기본값 | 설명 |
|---|---|---|
| `artist:` 처리 | 꺼짐 | 켜면 `by 이름` 또는 이름만으로 변환 |
| 중복 제거 | 켜짐 | 같은 태그는 처음 것만 남김 |
| 공백 → `_` | 꺼짐 | `blue eyes` → `blue_eyes` |
| 중첩 | 안쪽 값 우선 | "곱하기"로 두면 NAI 원래 동작 |
| 내 네거티브를 앞에 | 켜짐 | 병합 순서 |

`artist:` 는 기본적으로 **그대로 통과**합니다. Danbooru 태그로 학습된 모델
(Illustrious, NoobAI, Pony 등)은 이 형식을 그대로 읽습니다.

## 배포

정적 파일 하나라 어디든 올라갑니다.

**GitHub Pages** — 저장소에 `index.html`을 올리고
Settings → Pages → Source를 `main` 브랜치 루트로 지정

**Netlify / Vercel / Cloudflare Pages** — 폴더를 드래그 앤 드롭

**로컬 공유** — 파일 하나만 보내면 됩니다. 압축할 필요도 없습니다.

**로컬 서버** (선택)
```bash
python3 -m http.server 8000
# http://localhost:8000
```

> `file://` 로 직접 열면 일부 브라우저에서 클립보드 API가 막히지만,
> 자동으로 구형 복사 방식으로 넘어가므로 복사 버튼은 정상 동작합니다.

## 기술 사양

- 의존성 **0개** — 프레임워크, CDN, 웹폰트 전부 없음
- 자주 쓰는 Danbooru 태그 1,100여 개 내장 — 오타를 찾아 교정 제안 (사전에 없는 태그는 그대로 통과)
- `태그 사전 추가` 버튼으로 txt/csv 태그 목록을 불러와 사전 확장 가능
- 약 45 KB, 단일 파일
- 입력 내용은 **브라우저 밖으로 나가지 않습니다.** 네트워크 요청이 아예 없습니다
- 시스템 폰트만 사용 (한글 환경에서 Pretendard / D2Coding 있으면 자동 적용)
- `prefers-reduced-motion` 존중, 키보드 포커스 표시, 모바일 대응
